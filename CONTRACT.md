# Integration contract

Node >=22.13, native SQLite. Browser modules served from project root. No secrets in client.

Document schema (core.mjs): `{schemaVersion:1,title,description,theme:{background,surface,text,muted,accent,font,radius},pages:[{id,name,path,sections:[{id,type,eyebrow,title,body,button:{label,href},image,items:[{title,body,price,href}]}]}]}`. Section types: hero, features, gallery, stats, pricing, faq, cta. Optional image omitted by default. Three themes: editorial, midnight, studio. `seedVariants(brief, source)` returns three `{id,name,document}` variants. `validateDocument(input)` returns clean bounded canonical document or throws. `renderDocument(document,{pageId,editing=false})` returns full HTML. Editing mode posts `{type:'mosaic-select',sectionId,field}` to parent on click. Export supports `renderReact(document)` returning `{jsx,css}`. All rendered user/model text escaped. Main owns core.mjs and import.mjs.

Project JSON: `{id,name,brief,source:null|{url,title,description,text,headings,links,images},variants:[{id,name,document}],activeVariant,revision,createdAt,updatedAt}`. Versions separate API. Frontend stores drafts client-side but persists explicitly on save, with optimistic revision check. Version snapshot contains name,brief,source,variants,activeVariant.

API response JSON except exports. Error `{error,code}`. Credentials same origin cookie. GET `/api/config` -> `{aiConfigured,billingConfigured,registrationEnabled,localMode}`. GET `/api/me` -> `{user:null|{id,email,name,plan},usage:{used,limit}|null}`. POST `/api/auth/register` body `{email,password,name}`, POST `/api/auth/login` body `{email,password}`, POST `/api/auth/logout`.

GET `/api/projects` -> `{projects}`. POST `/api/projects` body `{name,brief}` -> `{project}` with seeded explicitly sample variants. GET `/api/projects/:id` -> `{project}`. PUT same path body project including revision -> `{project}`, 409 if stale. GET `/api/projects/:id/versions` -> `{versions:[{id,label,createdAt}]}`. POST same body `{label}` snapshots SAVED project -> `{version}`. POST `/api/projects/:id/restore` body `{versionId,revision}` -> `{project}`. DELETE project endpoint optional.

POST `/api/import` body `{url}` -> `{source}` (public static HTML fetch; scripts never executed). POST `/api/projects/:id/generate` body `{brief,source,revision}` -> `{project}`. POST `/api/projects/:id/chat` body `{instruction,variantId,revision}` -> `{project,message}`. AI unavailable returns 503 `AI_NOT_CONFIGURED`, never template fallback. Generation receives canonical schema and requires 3 variants, chat modifies actual document. GET `/api/projects/:id/export?format=html|react|json&pageId=...&variantId=...` -> attachment. React returns JSON `{jsx,css}` download file if no ZIP support.

GET `/api/billing` -> `{plan,usage,plans,billingConfigured}`. POST `/api/billing/checkout` body `{plan:'pro'}` -> `{url}` or 503 configuration error. POST `/api/billing/portal` -> `{url}`. Stripe signed webhook `/api/billing/webhook`, server plan updated only by verified events. Authentication required for all project/import/generate/chat/billing APIs; anonymous sample UI available without persistence. Local preview offers explicit local workspace session: POST `/api/auth/local` ONLY loopback when LOCAL_WORKSPACE=1 and NODE_ENV not production -> logged-in local account. No silently auto-login.

Frontend owner: index.html, app.js, styles.css, landing.html, landing.css. Backend owner: server.mjs, store.mjs, ai.mjs, billing.mjs. Main owner: core.mjs, import.mjs, package.json, test files, deployment and README. Never edit other owner's files without coordination.

## v0.3 commercial extension (supersedes the Pro-only billing contract above)

GET `/api/plans` is public and returns `{billingConfigured,currency:'usd',plans:[{id,name,description,limit,projectLimit,features,amount:null,priceDisplay,intervals:{monthly:{available},yearly:{available}}}]}`. IDs are free/pro/studio/business. No Stripe secret or price ID is public. UI never invents amounts or discounts. GET `/api/billing` additionally returns `subscription:null|{status,interval,currentPeriodEnd,...}`. POST checkout accepts `{plan:'pro'|'studio'|'business',interval:'monthly'|'yearly'}`; omission of interval keeps monthly compatibility. Valid configured recurring Stripe prices are verified before creating checkout. Signed webhook retrieval determines actual entitlement; downgrade preserves existing project edits and limits only new projects.

`createAIProvider` exposes providerType. AI_PROVIDER=anthropic uses native Messages, x-api-key, anthropic-version and a forced return_website data tool; compatible retains Chat Completions. All tests use local fixture services. Sources may additionally include contentSections (12 bounded heading/body pairs) and navigation (15 safe labelled URLs). These survive project persistence and feed the model as untrusted source data.
