BEFORE YOU START

Clear expectations.

What happens when I continue to the studio?

Your URL and brief travel in the address fragment, not a query string, for review in the studio. Continuing does not create a project, import a URL, call a model or start checkout. Once you choose an import or AI action, the relevant content is sent to the workspace server and, for AI, its configured provider. Avoid including passwords or private credentials.

Can I try Mosaic without an account?

You can explore and manually edit the labeled sample in your browser tab. Server saving, URL import, AI requests and API exports require a signed-in account or an explicitly enabled local workspace session. Availability is reported above; an anonymous sample is not a saved project.

Will a URL import reproduce my entire website?

The importer reads public static HTML and extracts readable content with its source. It does not run the site's scripts or copy the original design. Script-heavy pages may provide incomplete content. Public DNS addresses and redirects are checked by the server when you explicitly import.

Are the examples generated by AI?

No. The three preview websites and the before/after comparison are original, curated examples for fictional projects. They are illustrative, not customer results. AI generation in the studio requires a connected model, workspace access and an explicit request.

Is AI generation free?

Exploring the sample and entering a starting brief do not call a model. AI generation uses the workspace's configured provider and reported allowance; provider costs may apply. Paid subscriptions are recurring and become available only when billing is configured. Review the plan and checkout terms before confirming a purchase.

Does Mosaic host or publish my site?

Mosaic exports HTML, a React project or the structured design document. You arrange deployment, hosting and a custom domain separately. An export is not a published website.
