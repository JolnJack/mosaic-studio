# Product review and scoped corrections — 2026-10-10

## What was actually inspected

Read-only inspection of https://redesignr.ai/ in a real browser: desktop landing composition, URL/manual-design controls, new-website mode, public walkthrough, and the loaded https://redesignr.ai/themes directory. No account was created, paid preview unlocked, model request submitted, or proprietary code/assets downloaded or reused.

The reference presents the input task before the editor; its public form separates existing-site and new-site inputs. Its walkthrough illustrates side-by-side designs. Its theme directory has category, style, layout, and light/dark filters with real preview cards. Public marketing and a walkthrough do **not** independently prove the quality of paid generation, export, hosting, or backend behavior.

Visual direction: independent Amadeu identity, restrained graphite and violet, concise action labels, product results over ornamental artwork. Not a copy of the reference's branding, mascot, imagery, typography assets, or code.

## Acceptance for this correction

- Landing input survives the handoff and authentication without automatically creating a project or calling a model.
- Choosing a variant changes the actual current document, retaining undo and saved revision behavior.
- Preview and comparison use the same renderer as export; they are not mock screenshots.
- Unconfigured AI/payment remains explicitly unavailable, not simulated as successful.
- No additional purchase, third-party paid API request, or DNS change.
- Browser check the changed flows and capture actual UI; run relevant tests after integration.

## Still outside the verified release

This is a constrained document editor, not a general-purpose visual DOM/CSS editor. Three built-in sample directions are not a large industry template library. Static HTML extraction is not full JavaScript-site crawling. Screenshot input, arbitrary custom layouts, real-model design quality, account recovery/email verification, collaboration, a verified Stripe test-account lifecycle, production load/security review and public domain deployment remain uncompleted. Do not describe this correction as reference parity or a finished commercial platform.
