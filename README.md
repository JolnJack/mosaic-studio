# Amadeu / Mosaic Studio

独立开发的 AI 网站设计平台工程。提供官网、工作台、统一页面模型、可视化区块编辑、模型适配器、公开网页内容导入、SQLite 账户与项目存储、版本管理、代码导出和 Stripe 订阅基础设施。源码与设计不来自 Redesignr.ai。

这份工程替代此前只有关键词模拟的静态演示。样例设计明确标注为样例；真实生成与对话修改走服务端模型接口，未配置模型时返回配置错误。

## 启动

需要 Node.js 22.13 或以上。不要直接双击 index.html：工作台需要服务器与数据库。

macOS 可以双击 Start.command 启动本地服务器（首次会安装依赖），再打开终端提示的网址。

```sh
npm ci
cp .env.example .env
npm start
```

打开 http://127.0.0.1:4173 看官网，打开 http://127.0.0.1:4173/app 看工作台。开发环境可以使用明确的“本地工作区”入口；也可以创建账户。服务器数据库保存在 data/，不同账户的项目相互隔离。

## 配置模型

在服务端 .env 中设置 AI_PROVIDER、AI_MODEL 和服务商密钥。AI_PROVIDER=anthropic 使用 Claude 原生 Messages API 与结构化 tool 输出，密钥可用 ANTHROPIC_API_KEY；AI_PROVIDER=compatible 保留 Chat Completions JSON 协议与 AI_API_KEY。AI_BASE_URL 留空使用所选提供商的默认地址。模型需返回符合统一数据结构的页面，生成接口要求三个不同设计方案。输出经结构校验，再进入与导出器相同的渲染器。没有配置真实密钥的环境不能验证模型生成质量。

“开发不额外花钱”不代表产品永久免费。开发测试只连接本地测试服务，支付使用受控夹具；商用运行时，模型调用和基础设施仍有成本。不要为了开发填写真实付费密钥；没有支付配置时，界面仍展示套餐，但不能发起真实购买。没有任何自动免费 AI 或保证可领取的创业积分。

导入结果保留原站标题与段落的对应关系（最多 12 个内容分组）、导航链接和来源；这些数据供模型参考，不是对原站视觉的像素级复原。

URL 导入读取公开静态 HTML 的标题、描述、正文、结构与链接，不执行目标脚本、不复制参考平台代码或受保护素材。需要 JavaScript 登录或渲染的站点可能无法获取完整内容。导入校验所有解析地址，并将连接固定到校验过的公网 IP；重定向重新检查。当前本机的系统 DNS 返回代理测试网段，因此 .env.example 使用明确的公共 DNS-over-HTTPS 配置，详见 DEPLOYMENT.md。

## 页面与导出

统一页面数据结构支持多页面和 hero、features、gallery、stats、pricing、faq、cta 区块。编辑文本、配色、字体、圆角以及区块顺序后，同一数据用于画布和代码导出。可保存项目快照、恢复版本并使用 revision 防止旧页面覆盖新保存。

- HTML：独立页面文件。
- 整站 HTML ZIP：所有页面、导航、website.json。
- React ZIP：React/Vite 工程、每页 JSX、CSS、website.json。
- JSON：结构化页面数据。

React 导出通过经过校验与转义的静态 markup 保持与画布一致，目前不生成细粒度可复用 React 组件。用户需在发布前确认业务文案、联系地址、外链和图片使用权限。

## v0.4 体验修正

对公开参考产品做了实际页面与交互审查，具体差距和范围见 REFERENCE-REVIEW.md。本轮重做的是产品入口、项目起步、真实方案预览与比较、只读预览和可视区块库，不是参考产品功能等价声明。

官网 URL/描述输入只把草稿传入工作台，放在地址片段中而非请求查询参数；工作台消费后移除该片段。不在跳转时自动创建项目、调用模型或发起支付。登录后仍需明确提交，才创建或导入项目。

URL 起步先检查并导入内容，再创建项目；导入失败不留下空项目。创建成功但保存失败时保留同一账户的项目与来源供重试，退出账户会清理起步缓存。只读预览保留页面内部锚点，禁用外部/文件导航；多页面用预览选择器切换。导出的网站仍保留正常链接。

官网展示的 Morrow、Relay、Fold 是独立编写、可交互的虚构策展示例，不是客户案例，也不是模型生成证明；这些展示页不等于编辑器拥有同等数量的完整行业模板。

三个方案的比较展示当前页面模型实际渲染的内容，不是静态宣传截图。模型生成的新方案还须有三个不同的区块类型/布局组合，仅改配色、标题或 ID 会被拒绝。这只能排除一种低质量结果，不能证明真实生成品质已达到成熟产品。

分栏、堆叠、居中、大卡片区块布局在画布和导出中使用同一规则。图库条目可保留安全的自有图片 URL；图片仍是远程引用，不会自动下载或授予版权。内置几何插画是样例占位，不是用户网站的真实照片。

## 账户与订阅

密码使用带随机盐的 scrypt；会话凭据仅在服务端哈希保存，通过 HttpOnly cookie 登录。项目接口检查归属。模型用量在发请求前预留，失败释放，成功保存后提交。

订阅设施包括 Stripe Checkout、Customer Portal、带时间校验的 webhook 验签、幂等事件处理和按真实订阅状态更新权益。未配置时不可发起购买。真实收费、退款和订阅生命周期尚须在自己的 Stripe 测试账户验证。

产品分 Free、Pro、Studio、Business 四档，支持月付与年付。套餐的 AI 请求额度、项目上限由服务器统一提供，不由前端决定；默认额度只是可调整的产品配置，不是经营成本保证。每次成功保存的 AI 生成或对话修改算一个请求，失败返还预留额度；不宣称按真实模型 token 计费。

各收费档通过 STRIPE_PRICE_套餐_MONTHLY / YEARLY 绑定你自己的 Stripe 价格。保留 STRIPE_PRICE_PRO 作为 Pro 月付兼容配置。未设置价格时展示“Coming soon”，不虚构美元价格或优惠；实际金额、税费与续订条款以 Stripe 结账页面为准。结账前校验 Stripe 价格处于激活状态、USD、匹配月付或年付。订阅变更以服务器验证的 Stripe 状态为准，访问成功返回页不会自动升级。

套餐降级或到期不会删除已有项目，也不会阻止编辑已有项目；达到当前套餐项目上限时只限制新建。年付用户的 AI 请求额度仍按自然月刷新。

## Cloudflare 免费托管通道（2026-10-11）

配置使用 `app.amadeu.tech`，API 初期同源，不购买 VPS，不升级 Workers 套餐。现有 `amadeu.tech` 简历原型和邮箱解析保留；首期 Mosaic 首页与工作台分别为该子域的 `/` 与 `/app`。真实发布状态以 TEST-REPORT.md 最新记录为准，不把配置当成上线。

```sh
npm ci
npm test
npm run check
npm run worker:check
npm run worker:test
# 仅在自己已授权的 Cloudflare Free 账户中发布：
npm run worker:deploy
```

Wrangler 已锁定版本；构建仅复制 11 个前端文件，禁止把后端、数据库、配置密钥和源码包作为静态文件公开。账户数据、版本、会话和用量保存在 SQLite Durable Object；IP 与账户限额、并发租约和定位凭据也持久化，不依赖单次进程内存。定位 Cookie 不是登录凭据，仍须独立的随机会话校验。

2026-10-11 已实际发布上述公开 Beta，公网账户、保存、版本恢复、导出和重新登录后重开通过核验。生产环境安全 URL 导入实测失败，因此 URL_IMPORT_ENABLED=0，返回 503 IMPORT_UNAVAILABLE，前端明确提示使用 Design brief；不会关闭 TLS 校验或失去固定公网 IP 的安全保证。Node 本地导入路径保留，workerd 本地测试显式启用导入只用于兼容测试，不是生产成功证明。这不是完整浏览器渲染服务。

当前不配置付费模型或 Stripe 密钥；样例、结构化编辑、保存与导出不需要购买额度。未来客户收费档位保留，但当前不能真实购买或声称已接入付费 Claude。免费套餐达到限额会停用相关能力，不自动升级；正式收费运营前仍须验证模型质量、真实支付、邮件验证、找回密码与灾备恢复。
